# Arbetstid

A simple time tracking and pay calculator, built as an installable web app (PWA). I used it to log my hours during a summer job.

**Live:** https://netsrot1150.github.io/Arbetstid/

## Features

- Monthly calendar where you log hours per day
- Set your hourly rate and see your total earnings for the month
- Works offline and can be installed on your phone's home screen
- All data is stored locally in your browser — nothing is sent anywhere

## Tech

Plain HTML, CSS and JavaScript — no frameworks or build step. A service worker (`sw.js`) and `manifest.json` make it installable.

> The app's interface is in Swedish.
